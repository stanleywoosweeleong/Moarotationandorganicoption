# 虫药轮替 · Pest MoA

A bilingual (中文 / English), offline-capable PWA that helps Malaysian growers
rotate insecticides by IRAC mode-of-action group to slow resistance, and pairs
each chemical with a certified-organic alternative (Mr. Ganick) to support a
**"Chemical Once, Organic Once" / 一次化学 · 一次有机** reduced-chemical-use approach.
Built from Mr. Tee's *Bunting A* MoA rotation chart and the Baba Gardening
Mr. Ganick product catalogue.

It has four tabs — **机制库 / MoA Library**, **轮替助手 / Rotation Helper**
(with a cross-resistance "Caution" tier, a built-in explainer, and an
organic-first alternate), **有机 / Organic** (the Mr. Ganick range), and
**调配顺序 / Tank-Mix Order** (with the Mr. Ganick mixing colour-code legend).

Repo: https://github.com/stanleywoosweeleong/Moarotationandorganicoption

## Editing & rebuilding

1. Edit **`index.app.jsx`** (this is the app).
2. Rebuild:
   ```bash
   bash rebuild.sh index.html
   ```
   First run downloads the build tools (Tailwind, Babel, React) into
   `node_modules/` — one time, then it works offline. Needs Node.js + Python 3.
3. Commit the regenerated `index.html` (and `index.app.jsx`).

The build inlines Tailwind (only the classes you use), precompiles the JSX to
plain JS, and bundles React — so the result is one self-contained file with no
CDN dependencies. It preserves the `<head>` (title, icons, manifest, meta), so
those survive every rebuild.

## Deploying to GitHub Pages

Put **both** of these in the same folder of the Pages repo:

```
index.html
sw.js
```

That's it — all icons and the manifest are embedded inside `index.html`, so
there are **no icon files to add**. Keeping `index.app.jsx` and the build kit in
the same repo is harmless (Pages just stores them; users never load them) and
means you can always come back and edit.

> **`sw.js` must sit next to `index.html`** (same folder). A service worker can
> only control pages in its own folder and below.

## Offline support

- The app caches itself on first load and then works with **no connection** —
  Library, Rotation Helper, Tank-Mix, the explainer, language and font settings
  all run locally.
- **First visit must be online** (the worker can't cache what it's never seen).
- **Needs HTTPS** — GitHub Pages provides it. Opening the file from disk
  (`file://`) won't activate the worker.
- Page loads are **network-first**, so content updates reach users automatically
  when online; the cached copy is the fallback offline.
- The external MRL / DT50 links open other websites, so those still need a
  connection — the core app does not.
- To force every device to drop old caches after a big change, bump
  `CACHE_VERSION` at the top of `sw.js` (e.g. `pestmoa-v19...` -> `pestmoa-v20...`).
  Normal content updates don't need this.

## Data & safety

All chemical data is curated from Tee's *Bunting A* chart, cross-checked against
IRAC and peer-reviewed sources. Cross-resistance relationships and the MoA notes
are evidence-based. This is a **rotation guide, not a prescription** — always
check the product label, respect the pre-harvest interval, and never tank-mix
insecticides with glyphosate.

### Organic option (Baba Gardening Mr. Ganick)

The app carries **8 certified-organic biopesticides** from the Baba Gardening
Mr. Ganick range, supporting a **reduced-chemical-use / "Chemical Once, Organic
Once"** IPM approach: alternate a chemical spray with an organic one to cut
residue and break the resistance cycle. Every organic product's data —
active-ingredient string, solo/tank-mix dose, PHI (0 days), the **catalogue-listed
chemical tank-mix partners**, and the **Mr. Ganick 4-tier mixing colour code**
(green/orange/red/black) — is transcribed verbatim from the catalogue; nothing is
invented. The botanical extracts (e.g. "Faboideae/Papillionaceae plant alkaloid")
are *not* IRAC-classified single molecules and are labelled as botanical/biological.

How organics surface (this app leans organic-first, since it's for growers who
want organic but reach for chemicals during outbreaks):

- **MoA Library** — chemicals that have a Mr. Ganick partner show a green
  **"Organic pair" / 有机搭配** badge; expanding reveals the product(s), each
  labelled with the pest it applies to. An **"Organic pair only" / 只显示有机搭配**
  toggle filters the list to just those chemicals.
- **Rotation Helper** — a green **"Try organic first" / 先试有机** strip appears
  **above** the chemical suggestions for the selected pest. Organics are shown as
  a companion option, never slotted into the IRAC rotation grid (they have no MoA
  group).
- **Organic tab** — browsable cards for all 8 products with active, doses, PHI,
  covered pests, chemical partners, and the mixing colour code.
- **Tank-Mix tab** — the Mr. Ganick mixing colour-code legend below the
  formulation-order sequence.

Aphids are folded into the leafhopper/psyllid categories (they share sucking-pest
chemistry), so the 7-pest structure is unchanged. The organic dataset lives in
`ORGANIC_PRODUCTS` (with `MIX_CLASS` for the colour code) near the top of
`index.app.jsx` — edit there, then rebuild. **Note:** banned-in-Malaysia
chemicals (Endosulfan, Dicofol, Methamidophos, Methomyl) have been removed from
the database; Chlorpyrifos is kept (restricted, and a Mr. Ganick partner) with a
clear warning.

## App icon & boot splash

The icon is a cream **pest** inside a two-arrow rotation cycle, where the arrows
are **two-tone** to express the app's idea: a **green** arrow (organic spray) and
a **blue** arrow (chemical spray) — "Chemical Once, Organic Once." It sits on the
brand-green rounded square.

- `make_icon.py` → generates `icon.svg`.
- `embed_icon.py` → embeds `icon.svg` into `index.html` as the **favicon** +
  **apple-touch-icon**, and injects the in-app **boot splash** (brand-green
  overlay with the icon + app name, fades out when the app mounts). Idempotent —
  re-run it any time the icon changes; it replaces the marked blocks.
- The PWA manifest (`manifest.webmanifest`) carries the 192/512 PNG icons and a
  brand-green `background_color`, so the OS launch splash matches the in-app boot.

To change the icon: edit `make_icon.py` → `python make_icon.py` → `python embed_icon.py index.html`,
then regenerate the manifest icons (192/512) from the new `icon.svg`. No separate
icon files ship — everything is embedded in `index.html` and the manifest.
